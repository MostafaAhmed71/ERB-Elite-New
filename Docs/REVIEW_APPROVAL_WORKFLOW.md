# دورة اعتماد المراجعات — v2.17.0

المعلم → المشرف التربوي → المراجع → المدير → النشر للطلاب وأولياء الأمور.

- `pending`: وارد المشرف التربوي.
- `approved`: اعتمد المشرف، وارد المراجع (إعادة استخدام قيمة موجودة؛ لا تعديل enum).
- `awaitingPrincipal`: اعتمد المراجع، وارد المدير.
- `needsRevision`: ملاحظات إلزامية من المسؤول عن المرحلة، ثم يعيد المعلم رفع نسخة جديدة.
- `sentToParent`: اعتماد المدير النهائي والنشر.

إعادة الرفع تعيد الحالة إلى `pending` وتصفّر جميع اعتمادات الدورة السابقة. كل نسخة وقرار وملاحظة محفوظة في جدول سجل مستقل؛ يقرأه صاحب الملف والمشرف والمراجع والمدير فقط. تفرض قاعدة البيانات صلاحية الدور وترتيب المراحل وتمنع تغيير الملف أثناء الاعتماد. تستمر ميزة رفع المدير المباشر الموجودة سابقاً.

## التفعيل

1. تأكد من مشروع Supabase المستخدم فعلياً في `VITE_SUPABASE_URL`؛ لا تعتمد على config.toml وحده.
2. خذ نسخة قاعدة بيانات قبل الترحيل.
3. طبّق `supabase/migrations/20261025143446_exam_review_supervisor_workflow.sql` مرة واحدة على قاعدة المشروع الصحيحة.
4. انشر الواجهة من نفس الفرع، ثم اختبر الدورة بحسابات المعلم والمشرف والمراجع والمدير.
5. اختبر رفضاً من كل مرحلة، وإعادة رفع، وإشعارات الصندوق التالي، وعدم ظهور الملف للطالب قبل المدير.

الترحيل لا يغيّر المنشورات الحالية أو الملفات التي وصلت بالفعل إلى المدير. الملفات المعلقة تبدأ من المشرف بعد التفعيل. لا يُنشر فرع الواجهة على الإنتاج قبل تطبيق SQL. لا يوجد وصول لقاعدة المشروع عبر حسابات Supabase المتصلة وقت التنفيذ، ولذلك لم يطبّق الترحيل على الإنتاج.

## التحقق المحلي

اختبار PostgreSQL معزول عبر PGlite، ببيانات وأدوار وهمية، وليس اختباراً على قاعدة الإنتاج:

```bash
npm install --prefix /tmp/review-workflow-test @electric-sql/pglite
PGLITE_MODULE=/tmp/review-workflow-test/node_modules/@electric-sql/pglite/dist/index.js node scripts/test-review-workflow.mjs
npm run build
```

يغطي الاختبار المسار الكامل، والرفض من كل مرحلة، وإلزام الملاحظات، وإعادة رفع أربع نسخ، وتصفير الاعتمادات، ومنع تغيير الملف وتجاوز المراحل، وعزل سجل النسخ عن المستخدم الآخر والزائر، وتوجيه أول إشعار للمشرف، واستمرار رفع المدير المباشر. نجح 32 تحققاً.

نجح فحص TypeScript والبناء. يوجد خطأ ESLint سابق في `getCurrentWeekNumber` داخل constants.ts (`_date` غير مستخدم) خارج التعديل.
