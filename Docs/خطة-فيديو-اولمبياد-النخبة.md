# خطة فيديو موشن جرافيك — منصة أولمبياد النخبة 144هـ
### فيديو تعليمي كامل (~11 دقيقة) باستخدام Remotion

---

## ⚠️ استراتيجية العمل (اقرأها قبل ما تبدأ)

فيديو 11 دقيقة = **~19,800 frame**. لو طلبته من Claude Code دفعة واحدة، احتمال كبير يحصل تعارض في الأكواد أو أخطاء render وهتضيع وقت كتير تتبّع المشكلة فين.

**الطريقة الصح:**
1. ابدأ بـ **Prompt الأساس (Setup)** مرة واحدة بس — يبني نظام الألوان والخطوط والمكونات المشتركة (Scene wrapper, Card component, Arrow component...).
2. بعدها ادّي كل **Chapter** في رسالة منفصلة، واطلب render لجزء صغير منه قبل ما تكمل اللي بعده.
3. في الآخر تجمع كل الـ Chapters في composition واحدة نهائية.

ده هيخليك تتحكم في الجودة أول بأول بدل ما تكتشف مشكلة بعد 11 دقيقة كاملة.

## 🎨 نظام التصميم الموحّد (يتكرر في كل الفيديو)

```
الأبعاد: 1920x1080 @ 30fps
الخلفية: #0F1729 (كحلي غامق ثابت)

الألوان:
- Primary:  #3B82F6 (أزرق)
- Accent:   #FBBF24 (ذهبي - للتميز والنقاط)
- Success:  #34D399 (أخضر - للاعتماد/الموافقة)
- Text:     #F1F5F9 (أبيض مائل رمادي)

الخط: Cairo أو Tajawal (عبر @remotion/google-fonts)
- عناوين رئيسية: Bold 60px
- عناوين فرعية: SemiBold 42px
- نص عادي: Medium 32px
- تسميات (labels): Regular 24px

الاتجاه: RTL كامل (direction: rtl, textAlign: right)

قواعد الحركة:
- كل عنصر داخل: spring() [damping: 15, stiffness: 100]
- حركات مستمرة: interpolate + Easing.out(Easing.cubic)
- transitions بين مشاهد: fade + scale، ماتزيدش عن 15 frame
- فرق توقيت 5-10 frames بين أي عنصرين بيظهروا مع بعض
```

## 🧩 Prompt الأساس (ابعته الأول، مرة واحدة)

```
جهّزلي مشروع Remotion جديد لفيديو تعليمي طويل (11 دقيقة، 19800 frame @ 30fps، 1920x1080).

اعمل الأساسيات دي الأول قبل أي مشهد:

1. Design tokens في ملف theme.ts:
   - الألوان: primary #3B82F6, accent #FBBF24, success #34D399,
     background #0F1729, text #F1F5F9
   - تحميل خط Cairo عبر @remotion/google-fonts

2. مكونات مشتركة قابلة لإعادة الاستخدام:
   - <SceneWrapper> : خلفية + padding + دعم RTL كامل
   - <TitleCard> : عنوان رئيسي بيدخل بـ spring من تحت + fade
   - <InfoCard> : كارت (أيقونة + عنوان + وصف قصير) بيدخل بـ spring من الجانب
   - <FlowArrow> : سهم متحرك بين خطوتين (يستخدم في شرح الـ workflows)
   - <RoleBadge> : بادچ لعرض اسم الدور مع أيقونة مميزة له
   - <Counter> : رقم بيعد تصاعديًا (للنقاط)
   - <Timeline> : خط زمني أفقي مع نقاط تدخل بالتتابع

3. اعمل ملف Root.tsx فاضي بس بيسجل composition واحدة اسمها "FullVideo"
   بمدة 19800 frame، وسيبلي مكان أضيفله الـ Sequences بعدين.

بعد ما تخلص المكونات دي، اعمل render لثانيتين بس فيهم TitleCard
وInfoCard كعينة تجريبية، وابعتلي أشوفهم قبل ما نكمل بباقي الفيديو.
```

## ✅ ملاحظات أخيرة

- لو أي Chapter طلع بايظ (توقيت متزاحم، ألوان غلط)، ارجع للـ Chapter نفسه وقوله يصلح بدل ما تكمل قدام.
- بعد كل الـ Chapters، اطلب من Claude Code "راجع كل الـ Sequences وتأكد إن مافيش تداخل في الـ frames بينهم" قبل الـ render النهائي.
- الفيديو الكامل (11 دقيقة) هياخد وقت render أطول بكتير من المقاطع الصغيرة — متستغربش لو استنى شوية في الآخر.
