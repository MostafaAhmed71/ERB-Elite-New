# شرح منصة أولمبياد النخبة 144هـ — الدليل الكامل

> وثيقة مرجعية شاملة لكل المستخدمين: ما هي المنصة، كيف تعمل، وما يفعل كل دور.

---

## 1) ما هي المنصة؟

**أولمبياد النخبة 144هـ** منصة مدرسية متكاملة تهدف إلى:

1. **التحفيز بالنقاط** — مكافأة السلوك الإيجابي والإنجاز والمبادرة والنشاط.
2. **الشؤون الأكاديمية** — واجبات، خطط أسبوعية، جداول، ومتابعة مرحلية.
3. **الاختبارات الإلكترونية** — بناء أسئلة، تفعيل اختبارات، وتحليل الأداء.
4. **الشفافية للأسرة** — ولي الأمر يتابع ابنه لحظياً.
5. **العرض الحي** — لوحات متصدرين على الشاشات داخل المدرسة.

الشعار التشغيلي: **نحو القمة بالتميز**.

---

## 2) لمن المنصة؟ (الأدوار)

| الدور | المسؤولية باختصار |
|---|---|
| **الطالب** | يتابع نقاطه، يحل الاختبارات، يسلّم الواجبات، يستبدل المكافآت |
| **ولي الأمر** | يشاهد أداء الابن: نقاط، حضور، نتائج، واجبات |
| **المعلم** | يمنح نقاطاً، يتابع فصله، ينشر واجبات وخططاً |
| **رائد النشاط** | يشغّل البرنامج يومياً: اعتماد نقاط، حضور، أنشطة، تقارير |
| **المشرف التربوي** | يبني الاختبارات والتحليلات وبنك الأسئلة |
| **الوكيل** | يشرف أكاديمياً على مرحلته |
| **مدير المدرسة** | إدارة المستخدمين، البيانات، المؤشرات التنفيذية، الإشراف العام |

> بعد تسجيل الدخول تظهر لكل مستخدم **قائمته الجانبية فقط** حسب دوره — لا يرى شاشات الأدوار الأخرى.

---

## 3) تسجيل الدخول والبداية

1. افتح رابط المنصة في المتصفح (يُفضَّل Chrome أو Safari).
2. أدخل البريد الإلكتروني وكلمة المرور المُسلَّمة من إدارة المدرسة.
3. عند أول دخول قد يُطلب تغيير كلمة المرور — اختر كلمة قوية واحفظها.
4. تُوجَّه تلقائياً إلى لوحة دورك.

**نصائح أمان**
- لا تشارك كلمة المرور.
- إن نسيت الدخول: تواصل مع رائد النشاط أو مدير المدرسة لإعادة التعيين.
- الطلاب وأولياء الأمور قد يُنشَأ حسابهم عبر **توليد الحسابات** من المدير.

## 4) نظام النقاط (قلب الأولمبياد)

### الفكرة
كل مشاركة إيجابية تُكافأ بنقاط ضمن محاور (مثل: نشاط، سلوك، إنجاز، مبادرة). النقاط تظهر في:
- رصيد الطالب
- ترتيب الطلاب داخل الفصل
- ترتيب الفصول
- مستويات التميز (مثل برونزي / فضي / ذهبي…) حسب إعدادات البرنامج

### مسار المنح المعتاد
1. **المعلم** يختار طالباً (بحث أو مسح بطاقة QR) + نشاطاً + عدداً من النقاط ويرسل الطلب.
2. الطلب يكون غالباً **معلّقاً**.
3. **رائد النشاط** يعتمد أو يرفض من **مركز النقاط**.
4. بعد الاعتماد تظهر النقاط فوراً في رصيد الطالب والترتيب.

### أنواع المنح
- **فردي:** لطالب واحد.
- **جماعي:** لنقاط الفصل ككل (ترتيب الفصول).
- **يدوي فوري (رائد النشاط):** تكريم سريع باعتماد مباشر.

### قواعد مهمة
- للمعلم غالباً **حد أسبوعي** للنقاط — لا يتجاوزه.
- النقاط المعلّقة لا تظهر للطالب حتى الاعتماد.
- **مؤشر العدالة** يساعد الإدارة على اكتشاف فصول تحصل على نقاط أقل من المتوسط.

## 5) دليل كل دور بالتفصيل

### 5.1 الطالب

**الهدف:** رؤية تقدّمك، إنجاز الواجبات والاختبارات، واستبدال النقاط بمكافآت.

| الشاشة | المسار | ماذا تفعل؟ |
|---|---|---|
| لوحتي | `/student` | النقاط، الترتيب، الإنجازات، نظرة عامة |
| واجباتي وخطتي | `/student/academic` | الواجبات والخطط الأسبوعية والتسليم |
| اختباراتي | `/student/exams` | فتح الاختبارات المفعّلة (محاولة واحدة غالباً) |
| محفظتي | `/student/portfolio` | سجل النقاط المعتمدة والإنجازات |
| متجر المكافآت | `/student/rewards` | استبدال النقاط بمكافآت |
| المتصدرون | `/leaderboard` | ترتيب الطلاب/الفصول |
| ملفي | `/my-profile` | البيانات، المستوى، الشهادات |

**خطوات سريعة**
1. ابدأ من **لوحتي** كل يوم.
2. راجع **واجباتي** وسلّم المطلوب.
3. إن وُجد اختبار مفعّل: ادخل **اختباراتي** وأجب بتركيز ثم أرسل.
4. تابع **المتصدرين** و**المكافآت** للتحفيز.

**أسئلة شائعة**
- *متى تُضاف النقاط؟* بعد منح المعلم واعتماد رائد النشاط.
- *لماذا لا أُعيد الاختبار؟* غالباً محاولة واحدة لكل اختبار حسب قواعد البرنامج.

### 5.5 المشرف التربوي

**الهدف:** قياس التعلّم بالاختبارات والتحليل ثم التدخل المبكر.

   - أداء الفصل
   - تحليل الأسئلة

   - مقارنة الطالب

## 7) الشؤون الأكاديمية (عبر الأدوار)

المكوّنات المشتركة تقريباً:
- **واجبات** — نشر، تسليم، متابعة
- **خطط أسبوعية** — تنظيم عمل الأسبوع
- **جدول دراسي** — الحصص
- **مواضيع دروس** — محتوى الدرس
- **مراجعات PDF** — مواد مراجعة للطلاب/أولياء الأمور
- **تواصل أكاديمي** — رسائل/طلبات حسب الصلاحية
- **تصدير وتقارير** — للإدارة والوكيل

كل دور يرى ما يخص صلاحيته فقط (معلم لفصله/مادته، وكيل لمرحلته، مدير للإشراف العام…).

## 8) الاختبارات الإلكترونية

1. المشرف يجهّز المواد → المهارات → بنك الأسئلة.
2. ينشئ اختباراً ويحدد الفترة ويفعّله.
3. الطالب يحل من **اختباراتي** (محاولة واحدة عادة).
4. النتائج تظهر للطالب/ولي الأمر حسب الإعدادات.
5. المشرف يحلل الأداء ويتدخل عبر **طلاب الخطر** وغيرها.

إن لم يظهر الاختبار للطالب: تحقق من التفعيل وتاريخ الفترة وربط الصف/المادة.

## 10) رحلة يوم دراسي نموذجية

1. **قبل الطابور:** رائد النشاط يعتمد النقاط المعلّقة.
2. **الطابور/الممرات:** شاشة المتصدرين تعرض الترتيب المحدّث.
3. **الحصص:** المعلمون يمنحون نقاطاً ويعلنون واجبات/خططاً.
4. **الطلاب:** يسلّمون واجبات ويحلّون اختباراً إن وُجد.
5. **أولياء الأمور:** يتابعون الملخص في المساء.
6. **الإدارة:** تراجع اللوحة التنفيذية أو تقارير العدالة أسبوعياً.

---

## 11) أسئلة شائعة عامة

**لا أستطيع الدخول**  
تحقق من البريد وكلمة المرور، أو اطلب إعادة تعيين من الإدارة.

**لا تظهر لي قائمة متوقعة**  
الدور في حسابك يحدد القائمة. راجع مع مدير المدرسة أن الدور مربوط بشكل صحيح.

**نقاط المعلم لا تظهر للطالب**  
غالباً معلّقة — رائد النشاط يعتمدها من مركز النقاط.

**ولي الأمر لا يرى ابنه**  
الحساب غير مربوط بالطالب — يتم الربط من إدارة المستخدمين أو توليد الحسابات.

**أين أدلة كل دور داخل النظام؟**  
رائد النشاط يمكنه فتح **أدلة المستخدم** وتصديرها PDF/HTML وتوزيعها.
